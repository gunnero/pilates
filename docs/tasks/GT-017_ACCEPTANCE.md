## Detailed scope decisions, not skipped implementations

- GT-009 has no pending/unconfirmed cash, provider-failure, partial-refund, accrual, overdue due-date, multicurrency or group/trainer allocation contract. These cannot have invented charts or fixture states. Full correction reversal uses the original receipt's effective period; negative revenue cannot arise from its constrained full-reversal model. Negative overpayment balance is supported/tested. See `docs/domain/cash-payments.md`, FinanceMetrics and `docs/domain/reporting.md`.
- Session capacity is non-null and positive by PostgreSQL constraint; active allocation cannot exceed configured capacity. Tests establish null rates for an empty denominator and the renderer retains an uncapped hypothetical ratio; no invalid zero/null-capacity record is inserted to weaken the invariant. A TrainingSession has one trainer snapshot, not a co-trainer assignment model. Group/trainer facts use that retained snapshot; cross-dimension unique people are expressly non-additive.
- Walk-ins use canonical active reservations and AttendanceRecord, so their present fact participates once. Reports do not infer a new attendance method or persist no-shows. GT-008's walk-in/finalization/correction regression tests remain authoritative for the writer; GT-017 fixtures/read tests check the resulting grain/counts. Historical deleted/reassigned/current outcomes are described in the dictionary, not falsely reconstructed.
- Synchronous exports are fresh authenticated requests, with no persisted job/status/token API or public link. Therefore queued-job deduplication, background retries and stale signed-URL tests are inapplicable. Forced audit/storage cleanup and permission-revocation overlap test the actual synchronous lifecycle. Each retry creates one bounded private file and its own audit evidence.
- No schema/index/projection change was necessary under measured budgets. Fresh/upgrade verification is real; there is no new destructive down migration to test. Historical GT migrations remain untouched.
- Chart presentation deliberately limits to60 buckets, with complete bounded tables; ranking/option truncation is explicitly labelled. Device/simulator signing/share delivery and real notification delivery remain inherited unexecuted environment checks, not claims established by JavaScript bundles.
